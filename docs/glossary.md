# Plain-language glossary — v0.10

The road's vocabulary, in plain words. The [core rules](../seed.md) are authoritative. This glossary defines terms without a second set of numerical tables.

| Term | Meaning |
| --- | --- |
| Ability / modifier | A character's STR, DEX, CON, INT, WIS, or CHA and its small bonus/penalty to a d20 check. |
| Advantage / Disadvantage | Roll twice, take higher/lower. They do not stack; normally cancel if both apply. |
| Active slot | One of four travelers who can act for the party. A substitute occupies a slot, never adds a fifth free action. |
| Background | One starting specialty chosen within the role. |
| Bond | An agreed relationship with another PC. |
| Boundary | Something the character says they will not sacrifice; it cannot control another player. Separate from real table safety boundaries. |
| Camp Action | An able traveler's one special activity on a Rest Day. Camp conversation is available every evening. |
| Cargo bundle | A game unit for a specific sacrifice: food, part, ammunition, barrel, or named personal cargo as listed in core. Not equal physical weights. |
| Chapter / segment | One of the seven numbered parts of the journey. A chapter can span multiple play sessions. |
| Condition / mark | An illness or injury and a count of recovery successes remaining, not a calendar-day countdown. |
| Crisis intervention | A role's reliable special response purchased with stated time/resources. |
| Cured / fresh food | Keeping stores versus newly acquired food with a dated expiry and holding cap. |
| DC | Difficulty Class: the total a check must meet. GM states it and consequences before rolling. |
| Dream | The concrete reason a traveler wants to reach Oregon. |
| Event | A situation generated for a travel leg or eligible Focus Day; prepared scenes can replace it. |
| Exhaustion | Cumulative fatigue and deprivation tracked from zero to six. Maximum one new level per calendar day. |
| Expertise | Professional work that succeeds when its stated conditions/costs are met. |
| Extended check | Three successes before two failures, varied contributors, stated stakes. Not needed for ordinary conversation. |
| Favor | A specific person offering a specific future benefit. Record when earned and spent. |
| Focus Day | Resolve one day separately because a decision or danger matters; it does not automatically add an event inside an existing leg. |
| Full / partial / failed group check | More than half succeed / at least one but no majority / nobody succeeds. |
| Hard travel | Reckless travel or any Forced March attempt; increases food and stock strain. |
| HP | Hit Points, a short-term injury buffer. Zero interacts with persistent wound state. |
| Inspiration | One held opportunity to gain Advantage, earned through meaningful personal stakes or a specified evening activity. |
| Jury-rig | Teamster's guaranteed repair using a part and time, no permanent wagon-capacity penalty. |
| Lame team | A living team unavailable for pulling until a Rest Day. |
| Layover | Another name for a Rest Day. |
| Leg / montage | Normally three travel days resolved together, one random event, all daily costs and conditions still accounted for. One log row is enough unless a checkpoint changes the calculation. |
| Marker | Simplified progress along the campaign map. Detour actual miles can differ. |
| Morale | Shared confidence. Low values provoke conversation and renegotiation, not involuntary PC desertion. |
| NPC / PC | Non-player character / player character. NPCs have goals and limits, not unlimited aid. |
| Promise | A specific commitment to a named person, with an agreed deadline if any. |
| Recovery | End-of-day condition checks or fed Rest healing; their rules are different. |
| Reserve | A previously named traveler a player can control after incapacity or death. No new supply package. |
| Rest Day | Zero travel, reduced food ration, healing, stock recovery, Camp Actions, one evening activity. |
| Shelter | Actual protection from a specific weather threat; ordinary canvas is not universal severe-weather protection. |
| Stabilization | Ordinary action restores 1 HP to a zero-HP patient; Doctor's named Stabilize intervention instead handles condition damage/recovery. |
| Stance | Cautious, Standard, or Reckless travel, determining speed, food, and event choice. |
| Technique | A learned role option gained at chapter 2 and chapter 5. |
| Wound state | Healthy, Wounded, Gravely Injured, Dead; healing HP alone does not improve it. |

Old terminology retired in v0.9: Ghost Tax, Background Bump, universal d20 event table, automatic desertion, disease-specific death countdowns, and permanent max-Wagon-HP repair costs. If an old sheet uses them, replace it with the versioned sheets in this packet.
